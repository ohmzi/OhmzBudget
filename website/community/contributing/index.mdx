# Contributing to FlyBudget

Welcome to the FlyBudget contributing guide. We are glad you are interested in helping improve the project.

FlyBudget is an open-source budgeting application, and contributions of all kinds are welcome, whether that is code, documentation, bug reports, or feature ideas.

Before you get started, please review the pages in this section to understand our expectations and guidelines.
